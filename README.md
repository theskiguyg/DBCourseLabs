## О репозитории

Репозиторий содержит выполненные лабораторные и семинарские работы
по дисциплине «Базы данных».

В рамках работ изучаются основы реляционных баз данных, язык
Transact-SQL (T-SQL), создание и выполнение SQL-запросов, получение
и обработка данных, а также работа с базой данных AdventureWorksLT.

---

## Используемые технологии

- **Microsoft SQL Server 2019**
- **Transact-SQL (T-SQL)**
- **Docker**
- **Visual Studio Code**
