# Лабораторная работа №1 — Введение в Transact-SQL

## Цель работы

Познакомиться с базовыми возможностями языка Transact-SQL (T-SQL) и научиться выполнять простые запросы `SELECT` для извлечения и обработки данных из базы данных `AdventureWorksLT2019`.

В ходе работы рассматриваются:
- получение данных из таблиц;
- выбор отдельных столбцов;
- формирование вычисляемых столбцов;
- преобразование данных;
- обработка значений `NULL`;
- использование функции `ISNULL`;
- объединение текстовых значений;
- формирование отчетных данных.

## Используемая база данных

В работе используется учебная база данных:

**AdventureWorksLT2019**

Основные таблицы, используемые в работе:

- `SalesLT.Customer` — информация о клиентах;
- `SalesLT.SalesOrderHeader` — информация о заказах клиентов.

## Структура работы

### Задача 1 — Извлечение данных по клиентам

Необходимо создать запросы для получения информации о клиентах компании:

1. Получить все сведения о клиентах.
2. Получить имена клиентов с использованием отдельных столбцов.
3. Создать список для обзвона с указанием продавца, имени клиента и номера телефона.

### Задача 2 —  Получение данных о клиентах и продажах

Необходимо подготовить отчетные данные:

1. Сформировать название компании вместе с идентификатором клиента.
2. Получить номер заказа с номером его редакции и преобразовать дату заказа в стандартный формат.

### Задача 3 — Получение контактной информации клиента

Необходимо научиться работать с отсутствующими значениями (`NULL`):

1. Сформировать полное имя клиента с учетом возможного отчества.
2. Определить основной способ связи с клиентом: электронная почта или телефон.
3. Определить статус доставки заказа на основе наличия даты отправки.

Для проверки обработки `NULL` используются изменения исходных данных с помощью операторов `UPDATE`, указанных в задании.

## Используемые технологии

- Microsoft SQL Server 2019
- Transact-SQL (T-SQL)
- Docker
- Visual Studio Code
- База данных AdventureWorksLT2019
